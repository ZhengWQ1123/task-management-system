# 界面截图

本文件夹用于存放系统运行后的界面截图。

## 截图说明

系统包含以下主要页面，建议截取以下界面：

1. **登录页** (`/login`)
   - 展示登录表单和测试账号说明

2. **仪表盘** (`/dashboard`)
   - 展示统计卡片和快捷操作

3. **授课计划列表** (`/plans`)
   - 展示所有授课计划及其状态

4. **授课计划详情** (`/plans/plan-001`)
   - 展示计划内容和AI评估结果

5. **审核管理** (`/review`)
   - 展示待审核计划列表

6. **审核详情** (`/review/plan-001`)
   - 展示AI评估结果和审核操作

7. **培养方案管理** (`/training-programs`)
   - 展示专业培养方案和课程标准
