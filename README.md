# 校级授课计划与复盘管理系统

一款面向高等院校的智能化教学管理平台，实现授课计划的在线提交、二级学院审核、教务处审批的全流程数字化管理。

## 功能特性

### 1. 授课计划管理
- 在线创建、编辑、提交授课计划
- 教学方案与考核要求管理
- 材料状态追踪（草稿→已提交→审核中→已通过/已驳回）

### 2. 三级审核流程
- **教师**：提交授课计划
- **二级学院**：初审材料
- **教务处**：最终审批

### 3. 专业培养方案
- 培养目标管理
- 课程标准维护
- 产业需求分析
- 与人培方案对齐

### 4. AI智能评估
- 阶段性材料自动分析
- 四维度评分（完整性、清晰度、对齐度、实用性）
- 个性化优化建议
- 辅助人工审核决策

## 技术栈

- **前端框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式方案**：Tailwind CSS
- **状态管理**：Zustand
- **路由**：React Router DOM v6
- **图标**：Lucide React

## 快速开始

### 环境要求
- Node.js >= 16
- npm 或 pnpm

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:5173 查看应用。

### 构建生产版本

```bash
npm run build
```

## 功能演示

### 教师角色
1. 登录 `teacher1` 账号
2. 创建新的授课计划
3. 填写课程名称、教学内容、考核方式
4. 使用"AI评估"功能分析计划质量
5. 提交审核

### 学院管理员角色
1. 登录 `college_admin` 账号
2. 在"审核管理"中查看待审核计划
3. 查看AI评估结果
4. 选择通过或驳回

### 教务处管理员角色
1. 登录 `academic_admin` 账号
2. 查看学院已通过的计划
3. 进行最终审批

## 设计理念

- **需求清晰**：直观的界面设计，功能一目了然
- **分段实现**：模块化开发，便于维护和扩展
- **快速迭代**：基于原型验证，持续优化体验
